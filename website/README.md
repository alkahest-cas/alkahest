# Alkahest landing page

Homepage for [alkahest-cas.github.io](https://alkahest-cas.github.io/). Plain static
HTML/CSS/JS in `src/`, published as-is to the Pages site root by
`.github/workflows/website.yml` on every push to `main` touching `website/**`.

- `src/index.html`, `src/styles.css`, `src/app.js` — the landing page
- `src/agent/index.html` — the Agent "coming soon" page
- `src/data/benchmarks.json` — benchmark data rendered by `app.js`; generated by
  `python benchmarks/website/run_all.py` (see `benchmarks/website/RESULTS.md`)

The docs (`/docs/`) and playground (`/playground/`) deploy into the same Pages site
from their own workflows and share the design tokens at the top of `src/styles.css`.

```bash
cd website
bun run dev     # http://localhost:3000
bun run build   # checks local links and that benchmarks.json parses
```
