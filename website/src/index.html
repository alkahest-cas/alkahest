High-performance computer algebra for agents and humans.

Exact symbolic mathematics in Python and Rust, built on FLINT and Arb. Results carry derivation logs and Lean 4 certificates; when Alkahest can’t answer correctly, it refuses with a coded error rather than guessing.

pip install alkahest

Python 3.9–3.13 · Linux x86_64, macOS arm64, Windows x86_64 · PyPI

cargo add alkahest-cas

Needs FLINT ≥ 3.3, GMP and MPFR at build time · crates.io · docs.rs

Built for agents

Answers an agent can check — or an honest refusal.

An LLM can’t tell a plausible wrong answer from a right one. Alkahest is designed so it doesn’t have to take the result on trust.

Lean 4 certificates certified

Supported results export a Lean 4 + Mathlib proof that typechecks independently of Alkahest. The boundary is generated, not hand-maintained: certifiable() tells you up front whether a shape will certify.

r = ak.integrate(x**2, x, 0, 1); print(r.certificate)
example : ∫ x in (0:ℝ)..(1:ℝ), x ^ 2 = 1 ^ 3 / 3 - 0 ^ 3 / 3 := by
  have hderiv : ∀ x ∈ Set.uIcc 0 1,
      HasDerivAt (fun x => x ^ 3 / 3) (x ^ 2) x := by
    intro x _
    simpa using (hasDerivAt_pow 3 x).div_const 3
  have hint := (continuous_pow 2).intervalIntegrable _ _
  exact intervalIntegral.integral_eq_sub_of_hasDerivAt hderiv hint

119 certified shape classes in the coverage ledger; every corpus certificate is typechecked against Mathlib in CI.

Refuses instead of guessing E-INT-004

Every error has a stable code, a message that says why, and a remediation hint. A non-elementary integral is a proof of non-existence, not a timeout.

ak.integrate(ak.exp(x**2), x)
IntegrationError: [E-INT-004] integrate: no elementary
antiderivative exists: the Risch DE v' + 2x·v = 1 has no
rational solution; ∫ exp(x²) dx is not an elementary function
Remediation: use a numeric integrator …

Wall-clock, step and memory budgets raise E-BUDGET-* instead of hanging an agent loop.

Kani-verified kernels model-checked

The integer and modular-arithmetic kernels underneath — mul_mod, pow_mod, CRT steps, modular inverses, integer square roots, bytecode bounds in the evaluator — carry Kani proof harnesses checked over their full input width.

alkahest-core/src/modular/mod.rs
#[kani::proof]
fn mul_mod_in_range_full_width() {
    let (a, b, m): (u64, u64, u64) = kani::any();
    kani::assume(m > 0);
    assert!(mul_mod(a, b, m) < m);
}

50 proof harnesses across 16 modules, run in CI.

Debuggable by construction

Every transforming call returns a derivation log of the rewrite rules it applied, plus a versioned JSON envelope with a verification status — cheap to log, easy to diff when a run goes wrong.

ak.integrate(x * ak.cos(x), x).to_dict(mode="compact")
{ "value": "cos(x) + x*sin(x)",
  "verification": { "status": "exactly_verified" },
  "certificate_status": { "certifiable": true },
  "steps": [ { "r": "int_poly_trig_ibp" }, … ] }

Plus crosscheck for differential testing against another CAS, and claim graphs for session provenance.
