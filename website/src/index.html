Results you can verify

Lean 4 certificates certified

Supported results come with a Lean 4 proof that checks independently of alkahest. Integrals and ODE/PDE solutions are proved by reflection through a verified checker, with a tactic fallback. certifiable() tells you in advance whether a result will get one

r = ak.integrate(x**2, x); r.certificate # tail of the Lean file

Refuses instead of guessing E-INT-004

When there is no answer, alkahest says so and says why. Every error has a stable code and a hint for what to do next

ak.integrate(ak.exp(x**3), x) # raises IntegrationError
[E-INT-004] integrate: no elementary antiderivative exists: ∫ e^(x³) dx …
Remediation: this integrand has no closed-form antiderivative in terms of elementary functions; use a numeric integrator or elliptic-integral library

Time, step and memory budgets raise E-BUDGET-* so a long call never hangs your program

Proven arithmetic kernels model-checked

The integer and modular arithmetic underneath everything is proven correct for every possible input with the Kani model checker

alkahest-core/src/modular/mod.rs
#[kani::proof]
fn mul_mod_in_range_full_width() {
    let a: u64 = kani::any();
    let b: u64 = kani::any();
    let m: u64 = kani::any_where(|m: &u64| *m > 0);
    assert!(mul_mod(a, b, m) < m);
}

50 proofs across 16 modules, checked on every pull request and nightly
